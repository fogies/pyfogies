# pyfogies

## System Dependencies

- Python

  <https://www.python.org/>

  Development uses version >= 3.14.

  On Windows, development uses Python Install Manager:
  
  <https://apps.microsoft.com/detail/9nq7512cxl7t>
 
  <https://docs.python.org/dev/using/windows.html>

- Poetry
  
  <https://python-poetry.org/>

  On Windows, using Python Install Manager:

  ```
  py -m pip install poetry
  ```

## Python Dependencies

Python dependencies in `poetry.lock`.

On Windows, using Python Install Manager and Poetry:

  ```
  py -m poetry install
  ```

## Activating Development Environment

On Windows:

```
poetry_activate.bat
```
